🚀 How to Publish Changes to GitHub Pages (3-Step Guide)

1
Export Updated Data & Organize New Photos

Download the updated sessions.json or other modified JSON files using the buttons above. If you added new photos, place them inside your local repository under assets/images/sessions/<session-id>/.

2
Replace Files in Your Repository

Copy the downloaded JSON files into the data/ folder of your local GitHub repository (or upload them directly on GitHub.com into the data/ folder).

3
Commit and Push to GitHub

Run git add ., git commit -m "Update portfolio sessions", and git push origin main. GitHub Pages will automatically deploy your live portfolio within 60 seconds!
